About

This is an example of a website using coffeebisquit (based on Jekyll's minima theme) for video stuff. You can find the coffeebisquit repo here: https://codeberg.org/DrewNaylor/coffeebisquit. Jekyll's minima theme and coffeebisquit are under the MIT License but some coffeebisquit-compatible software components will be under the AGPLv3+, like the GTS integration server software (but that will be in a separate repo); therefore, coffeebisquit is under the MIT license and integrates some other code that may be under other licenses as described in the readme's "Third-party libraries" section (like HLS.js version 1.6.12 (since that version appears to predate slopbot activity in its repo), used under the Apache License, version 2.0). See ./LICENSE.txt, ./coffeebisquit/LICENSE.txt, and files under ./MORE_LICENSES in the repo for more info.

coffeebisquit also uses these Jekyll plugins:

  • jekyll-seo-tag
  • jekyll-commonmark

The source for this particular example website and its output files is available here: https://github.com/DrewNaylor/coffeebisquit-example-website.
