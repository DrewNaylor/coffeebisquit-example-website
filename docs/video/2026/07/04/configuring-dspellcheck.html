Testing a video that's in HLS.

Something I noticed is that with PeerTube's subtitle files, they load from the server under the "lazy-static" folder instead of a local path so you would have to download and modify each video's subtitle files to point to a local copy of the subtitle file. However, I have changed my code to not use those m3u8 subtitle files but I might go back to that with HLS.js when I change my resolution-changing code to tell HLS.js to switch the quality level directly instead of me changing which m3u8 file is loaded. I'll still have to keep the version that loads caption files directly for non-HLS videos, though.
