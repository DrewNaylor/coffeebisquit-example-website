# coffeebisquit-example-website
coffeebisquit example website, hosted via git so the source can be easily read and on GitHub Pages because it's free real estate

You can check out how it looks at [https://coffeebisquit-example.drew-naylor.com/](https://coffeebisquit-example.drew-naylor.com/).

coffeebisquit source code available at [https://codeberg.org/DrewNaylor/coffeebisquit](https://codeberg.org/DrewNaylor/coffeebisquit). Note this website was built with coffeebisquit 0.1.1 which isn't a published release yet, that one fixes the torrent links where videos don't have their `video-id` and `videoroot` match (it uses `videoroot`).
